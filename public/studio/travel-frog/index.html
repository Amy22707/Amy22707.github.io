01 / WINDOWS

电脑上，解压后双击打开

  1. 下载对应版本的 Windows ZIP，右键选择“全部解压缩”，放到自己可写入的文件夹，例如“文档”或 D 盘游戏目录。
  2. 标准版双击 FrogNormal.exe；图鉴版双击 FrogGallery.exe。请保留整个文件夹，不要只拿走 EXE。
  3. 首次使用点击“导入存档”选择备份，或点击“开始新的旅程”。之后再双击 EXE，会直接进入已有旅程。
  4. 窗口左下角“存档”可打开管理窗口并导出备份。要导入另一份进度，先关闭游戏，再双击文件夹中的 存档管理.cmd，点击“导入存档”。
  5. 存档位于程序旁的 user-data/normal/ 或 user-data/gallery/。升级时保留此文件夹，迁移电脑时优先使用“导出存档”。关闭游戏窗口后，本地服务会自动退出。

需要 Windows 10 / 11 的 64 位系统，以及 Edge 或 Chrome。游戏使用独立应用窗口，不要求打开日常浏览器标签页。下载文件没有商业代码签名；若系统提示风险，请核实下载来源后自行决定是否继续。

02 / ANDROID

安卓手机，安装 APK 后独立游玩

  1. 在手机上下载对应 APK。系统询问时，只为当前浏览器或文件管理器允许“安装未知应用”，安装完成后可以关回此权限。
  2. 打开桌面的“旅行青蛙·中国之旅离线版”或“旅行青蛙·中国之旅图鉴版”。两个包可以同时安装，不覆盖官服客户端。
  3. 等待本地运行环境启动，选择“导入存档”，在系统文件选择器中选中 .frogsave、兼容 JSON 或完整初始化协议 JSONL；没有备份则点击“开始新的旅程”。
  4. 看到青蛙名字后点击“继续旅程”。日常游玩不需要电脑、ADB、模拟器或网络连接。
  5. 备份时点左下角“存档”，回到起始页选择“导出存档”，在系统保存窗口选择“下载”等容易找到的位置。

最低安装版本为 Android 7；运行依赖支持 WebAssembly 的现代 Android System WebView。若卡在运行环境加载，请更新 WebView / Chrome。覆盖安装同一版本可保留进度，卸载前务必导出备份。

03 / IPHONE, IPAD & WEB

用 Safari 添加到主屏幕

  1. 在 Safari 中打开上方对应版本的“在网页上玩”，不要使用聊天软件内置浏览器。
  2. 先从 Safari 分享菜单选择“添加到主屏幕”，然后从新桌面图标打开游戏。iOS 版本不同，浏览器页与桌面应用的存储可能分开，建议在桌面图标内导入存档。
  3. 等待运行环境就绪，选择“导入存档”并从“文件”中选择备份，或开始新的旅程。
  4. 点击“下载离线资源”，保持页面打开，等待按钮显示“离线资源已下载”。之后可断网重新打开该桌面图标，点击“继续旅程”。
  5. 换机、清理 Safari 网站数据或删除桌面应用前，先点击“导出存档”，将文件存入 iCloud Drive 或其他自己保管的位置。

其他设备也可直接使用网页版本。标准版与图鉴版的进度分开保存；更换浏览器、无痕窗口或设备时不会自动出现原存档，需要手动导入。

04 / YOUR SAVE

导入自己的备份，或在设备之间迁移

你手上的文件怎样使用
.frogsave本项目导出的完整离线进度，在相同版本中直接导入。
state.json / gallery_state.json兼容离线服务的状态文件，分别在标准版 / 图鉴版导入。
protocol_full_LOCAL_ONLY.jsonl包含完整登录初始化的官服协议记录，导入标准版；同一文件中的照片详情会一并保留。
原始 logcat TXT、APK、账号密码、手机截图不能直接作为完整存档导入；原始日志须先解析。账号密码和 APK 不含可直接恢复的完整服务器进度。

一次导出，一次导入

  1. 在旧设备结束当前游戏画面，进入“存档”→“导出存档”，得到 .frogsave 文件。
  2. 通过数据线、AirDrop、自己的网盘等方式传到新设备，保留文件后缀，不要发到公开评论区或源码仓库。
  3. 在新设备打开同一版本，点击“导入存档”。确认后进入游戏，核对青蛙名字、相册和物品。
  4. 两边不会自动同步。以后以最后游玩的设备为准，再次换设备时重新导出，避免旧备份覆盖新进度。

覆盖已有进度前会自动建立导入前备份。安卓与网页可在起始页点击“导出上次导入前的备份”取回被覆盖的进度；Windows 可在存档文件夹中的 import-backups 目录找到它。日记与已保存的照片图层包含在存档包中。标准版和图鉴版存档不能直接混用；导入标准版存档不会自动变成图鉴版。

05 / OFFICIAL-SERVER BACKUP

从官服保存自己的进度

已有本项目备份的玩家直接使用上方导入功能。还只有官服账号时，需要在官服仍能正常登录的设备上先保存完整登录数据；离线版不接收你的手机号、验证码或官服密码，也不能凭账号信息从已经关闭的服务器找回进度。

需要模拟器吗？在哪里登录？

已有 .frogsave、兼容 JSON 存档或完整初始化 JSONL 的玩家，直接在本地版中导入，不需要安装模拟器，也不需要登录官服。

  1. 先准备采集环境：当前工具需要能读取官服应用私有文件的安卓环境。可以使用已 root 的安卓设备，或在电脑上安装支持 root 的安卓模拟器并开启 root；不是要求把自己的日常手机 root。
  2. 安装原渠道的官服客户端：在这个安卓环境中安装与你原账号渠道相同、且与采集工具兼容的官方客户端。不要使用本地逆向版 APK 来登录官服。
  3. 在原游戏里登录：打开官服客户端，使用该渠道原有的登录方式进入账号。确认加载的是自己的青蛙，核对名字、库存和相册，然后退出官服，按下面步骤安装采集脚本、开始记录，再重新打开客户端加载进度。
  4. 采集后再导入本地版：解析日志得到 protocol_full_LOCAL_ONLY.jsonl，在标准版中选择“导入存档”。本地版不要求手机号、验证码或官服密码。

当前下方命令针对 com.aligames.lxqw.hhb 客户端。其他安卓渠道、iOS，以及微信或淘宝小程序的账号，必须先确认能在受支持的安卓客户端中加载同一份进度；仅手机号相同不代表存档互通。无法登录并读取原进度时，不能靠本地版凭空恢复该账号的存档。

以下采集流程适用于已支持的官方客户端，需要 Windows、Python 3.10+、ADB，以及能访问官服应用私有文件的 root 安卓设备或模拟器。普通手机安装离线 APK 不需要 root；这里的 root 仅用于采集自己的官服备份。

步骤 A：准备工具与原始客户端文件
  1. 从 源码仓库（上线后开放）下载源码 ZIP 并解压，在该目录打开 CMD。安装 Python 和 Android Platform Tools，让 python 与 adb 命令可用；连接多个设备时，每条 ADB 命令在 adb 后加 -s 设备序列号。
  2. 确认官服进度能正常加载，随后彻底退出官服应用。不要清理应用数据、卸载或删除缓存。
  3. 先打开安卓 shell，再取得 root，查找热更新脚本：
    adb shell
su
find /data/data/com.aligames.lxqw.hhb/files -type f -path '*/main.min.js#/*'
    记下当前已运行版本的完整文件路径。如果有多个结果，对照最近运行的资源版本，不要随便选第一个；如果没有此路径，当前客户端结构不适用本教程。
  4. 在仍打开的 root shell 中，将占位路径替换为上一步的精确路径，备份原文件：
    cat "实际完整路径" > /sdcard/Download/main.original.js
exit
exit
adb pull /sdcard/Download/main.original.js main.original.js
    保留原脚本，后面恢复时使用同一份文件。
步骤 B：开启本机采集日志，保留官服连接
  1. 在源码根目录执行：
    python tools\capture\prepare_capture_client.py --input main.original.js --output main.capture.js
    工具只打开协议分块日志，不改服务器地址。若提示补丁目标不匹配，停止操作，说明当前客户端版本尚未适配。
  2. 上传脚本，并在独立 root shell 中覆盖已确认的精确文件，不要删除文件或缓存目录：
    adb push main.capture.js /sdcard/Download/main.capture.js
adb shell
su
cat /sdcard/Download/main.capture.js > "实际完整路径"
exit
exit
  3. 打开一个单独的 CMD 窗口开始记录，再启动官服应用：
    adb logcat -v threadtime > official_raw_logcat_LOCAL_ONLY.txt
    保持窗口运行，不要在它里面输入其他命令。正常登录自己的账号，等待庭院与室内数据加载完成。
步骤 C：补齐照片与各模块，解析并导入
  1. 保持日志记录，在官服逐页打开相册、礼品盒和回收站；需要保留准确构图的照片，逐张打开大图。再打开动态相册、旅行日记、笔记、友情绘本、故事、图鉴、百科、家具、手工品、花圃与当前活动页面，等待加载完成。
  2. 登录初始化通常只有照片索引；未加载的历史照片不保证能还原原有图层位置。尽量在一次登录中完成浏览，不要为采集而领取、删除或消耗不想改变的内容。
  3. 退出官服，在采集窗口按 Ctrl+C 停止。回到源码目录的 CMD 执行：
    python tools\capture\parse_warehouse_capture.py --src official_raw_logcat_LOCAL_ONLY.txt --out official-backup
  4. 查看输出的 warehouse_summary_SHARE_SAFE.txt 与 album_coverage_SHARE_SAFE.txt。分块缺失或 JSON 解析失败应重新采集；相册缺失详情应补采对应照片。不是完整登录初始化的日志，导入会提示缺少必要数据。
  5. 将 official-backup\protocol_full_LOCAL_ONLY.jsonl 复制到目标设备，在标准版中“导入存档”。核对青蛙、库存、照片与日记后，导出一份 .frogsave 长期保存。
  6. 关闭官服应用，恢复同一精确路径的原脚本：
    adb push main.original.js /sdcard/Download/main.original.js
adb shell
su
cat /sdcard/Download/main.original.js > "实际完整路径"
exit
exit

原始日志和 LOCAL_ONLY 文件可能含账号凭据、设备标识与玩家互动数据，只留在自己设备上。用于恢复的是完整 LOCAL_ONLY 文件，不是脱敏的 SHARE_SAFE 文件。采集结束后恢复原脚本，避免持续记录账号信息。

06 / HELP

常见问题与兼容范围

下载慢、APK 无法安装？

文件托管于 GitHub Releases，部分网络环境下访问较慢。检查下载是否完整、设备空间与安装权限。若已安装旧的电脑连接型 APK，先导出进度；遇到签名不兼容时，不要直接卸载丢失存档。也可以先使用网页版本。

iPhone 离线打不开，或导入后找不到进度？

确认在同一桌面图标 / 浏览器中打开同一版本，而且完整离线资源已下载。Safari 页面与主屏幕应用可能使用不同存储，换入口时重新导入备份。不要用无痕浏览；设备空间不足时，系统可能回收网站数据。清理前先导出。

网页会上传我的存档吗？

游戏逻辑与存档在当前设备运行，网站只提供静态程序和资源；导入文件不发送到网站服务器。网页不会替你云端备份，请将导出的文件保存到自己设备或自己选择的网盘。

两版能同时玩吗？与官服有什么差别？

两版存档独立，可同时安装。离线版保留原客户端交互，无法从现有资料确定的服务端概率与时长使用本地规则；其他玩家互动不连接真人。图鉴版用于查看与体验收藏，不能将其资源规则同步回官服。

当前仍在进行跨平台测试，实体手机的系统兼容、存储回收与长期后台行为尚待完整验收。反馈入口会在上线后开放；请不要公开上传个人存档或原始日志。
