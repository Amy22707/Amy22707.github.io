Windows

  1. Download the Windows installer for your edition above. Choose an install folder and whether to add a desktop shortcut. The installer includes the game files and runs offline, shows installation progress, and lets you cancel. For a portable copy, download the Windows ZIP from the release page and extract the whole folder.
  2. Open FrogNormal.exe for Normal or FrogGallery.exe for Gallery. Windows v0.2.4 runs in its own desktop window using Microsoft WebView2 Runtime on 64-bit Windows 10 or 11. You can also launch the game from the Start menu.
  3. Choose 导入存档 (Import save) or 开始新的旅程 (Start a new journey). With a save in place, the launcher opens the game directly.
  4. To export, click 存档 (Save) at the bottom left. To import a different save, close the game, then open 存档管理.cmd and choose 导入存档. When upgrading, close the game and select your current install folder to keep user-data. To move to another folder, export a save and import it into the same edition at the new location.

macOS

IntelNormal DMGGallery DMG
  1. Check the chip in Apple menu → About This Mac. Choose arm64 for Apple silicon or x86_64 for Intel. The game requires macOS 13 or later.
  2. Open the DMG and drag the app to Applications. If macOS blocks the first launch, open System Settings → Privacy & Security and choose Open Anyway for this app.
  3. Create a new save or import a save for the same edition. Use the Save button or the app menu to export a backup. The two editions store progress separately.

Android

  1. Download and install the APK for your edition. If Android asks for permission to install unknown apps, allow it for the browser or file manager you are using. You can revoke it after installation.
  2. Open the app, then import a save or start a new journey. The editions have separate app icons and saves. They can coexist with the official app.
  3. To export, return to the start screen using 存档 (Save) and choose 导出存档 (Export save). Use Android's file picker to choose where to save the file.

Requires Android 7 or later and a System WebView that supports WebAssembly. Update Android System WebView or Chrome if loading stalls. Export your save before uninstalling.

iPhone, iPad and web

  1. Use the play link above. On iPhone or iPad, open it in Safari and choose Share → Add to Home Screen.
  2. Open the new home-screen icon and import a save or start a new journey there. Safari and the installed web app may store progress separately.
  3. For offline play, click 下载离线资源 (Download offline resources) and keep the page open until the download finishes. The full download is about 320 MB.

Other devices can play directly in the browser. Export a save before switching browsers, clearing site data or removing the app.

Move a save between devices

  1. Export a .frogsave file from the device with your latest progress.
  2. Transfer the file to the new device and import it into the same edition. Confirm your frog's name, album and inventory after opening the game.
  3. Importing over an existing save creates a backup. On Android and the web, use 导出上次导入前的备份 (Export previous save). On Windows, find it in the save folder under import-backups.

The export includes your travel diary and saved photo layers. Compatible offline JSON saves can also be imported into their matching edition. Devices keep their own progress and use these files to transfer it.

Back up your progress from the official server

You need an official client that can still sign in, a Windows PC with Python 3.10+ and ADB, and a rooted Android device or emulator that can read the official app's files.

A. Save the original client script

Close the official app. In CMD, connect to the device, open a shell, become root and locate the hot-update script:

adb shell
su
find /data/data/com.aligames.lxqw.hhb/files -type f -path '*/main.min.js#/*'

Identify the exact file used by the running client. Replace EXACT_PATH below with its full path and make a backup from the root shell:

cat "EXACT_PATH" > /sdcard/Download/main.original.js
exit
exit
adb pull /sdcard/Download/main.original.js main.original.js
B. Capture your official login and album

Download and extract the project source. Open CMD in that directory and prepare the logging patch. Put main.original.js in the same directory first.

python tools\capture\prepare_capture_client.py --input main.original.js --output main.capture.js
adb push main.capture.js /sdcard/Download/main.capture.js
adb shell
su
cat /sdcard/Download/main.capture.js > "EXACT_PATH"
exit
exit

Open a separate CMD window and start capture before opening the official app:

adb logcat -v threadtime > official_raw_logcat_LOCAL_ONLY.txt

Sign in and wait for your courtyard and room to load. Visit your albums, gift box, recycle bin, animated photos, diary and other screens whose progress you want to keep. Open individual photos to capture their layers. Close the app, then stop logging with Ctrl+C.

C. Import your backup and restore the client 
python tools\capture\parse_warehouse_capture.py --src official_raw_logcat_LOCAL_ONLY.txt --out official-backup

Check the generated summaries for missing data or parsing errors. Import official-backup\protocol_full_LOCAL_ONLY.jsonl into the Normal edition, then export a .frogsave. Keep the raw log and full protocol file on your own device. Restore the original script while the official app is closed:

adb push main.original.js /sdcard/Download/main.original.js
adb shell
su
cat /sdcard/Download/main.original.js > "EXACT_PATH"
exit
exit

Help

If a save appears missing, check that you opened the same edition and browser or installed web app. Your save stays on your device. The offline game uses a local travel diary in place of message bottles. Live multiplayer features and leaderboards require the official service.

Report issues with your device, edition and steps to reproduce. Keep personal saves and raw captures private.
